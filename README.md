# chatterbox-pdzd

Форк [Chatterbox Multilingual](https://github.com/resemble-ai/chatterbox) от Resemble AI (релиз `chatterbox-tts` 0.1.7, лицензия MIT) с исправлениями для **русской озвучки клоном голоса на обычном CPU**.

*English summary: a fork of Resemble AI's Chatterbox Multilingual 0.1.7 (MIT) focused on Russian TTS with voice cloning on CPU. It fixes an early-EOS bug, restores Russian stress marks (RUAccent), caches the voice profile, adds a Russian text normalizer for numbers, years, units, abbreviations and Latin names, and adds a CLI that cuts the model's trailing mumble and re-takes phrases with swallowed words (checked by a local faster-whisper). Everything below is measured on one laptop CPU and judged by ear by one person. Read the limitations section.*

---

## Как это сделано (честно)

- Проект для себя: нужна бесплатная локальная озвучка русского текста своим голосом, без платных API.
- Код и анализ сделал ИИ-ассистент **Claude (Anthropic)** по задачам и тестам автора репозитория. Автор слушал результаты и говорил, что не так, а ассистент искал причину, правил и перемерял.
- Каждое исправление ниже появилось после конкретной проблемы, найденной на слух или по замерам, а не «на всякий случай».
- Основа — код из пакета `chatterbox-tts==0.1.7` с PyPI, а не текущий `main` апстрима. Апстрим с тех пор менялся, и этот форк его не отслеживает.
- Модели (веса) не входят в репозиторий. При первом запуске они скачиваются с Hugging Face (`ResembleAI/chatterbox`).

## Что исправлено в коде модели

Все исправления помечены в коде комментарием `pdzd-fix`. Скрипт `apply_patches.py` умеет заново наложить их на чистые исходники 0.1.7; в этом репозитории они уже наложены.

| # | Проблема в 0.1.7 | Что сделано |
|---|---|---|
| 1 | **Фразы обрывались на полуслове.** В `alignment_stream_analyzer.py` в комментарии написано «3 одинаковых токена подряд», а код проверял только 2 последних. Проверка «текст уже закончен» при этом закомментирована. Любые два одинаковых речевых токена посреди фразы принудительно завершали генерацию. | После конца текста генерацию останавливают 3 одинаковых токена подряд, до конца — только настоящее зацикливание (8 подряд). |
| 2 | **Русские ударения молча не ставились.** Код ждал необязательный пакет `russian_text_stresser`: его нет на PyPI, он под GPL-3.0 и конфликтует по зависимостям. Без него ударения просто пропускались, без ошибки. | Ударения ставит [RUAccent](https://github.com/Den4ikAI/ruaccent) (Apache-2.0), с омографами: за́мок/замо́к, му́ка/мука́. Это делается до NFKD-нормализации. Ручное ударение `м+ука` имеет приоритет. |
| 3 | **Профиль голоса пересчитывался при каждом вызове** `generate()`: три энкодера на каждую фразу. | Профиль кэшируется по пути и времени изменения файла-образца. В CLI его можно сохранить в `.pt` и больше не пересчитывать. |
| 4 | `max_new_tokens` и число шагов декодера (`n_cfm_timesteps`) были зашиты в коде. | Вынесены в параметры `generate()`. |
| 5 | После переименования пакета падал `version("chatterbox-tts")`. | Есть запасное значение версии. |

## Что добавлено

**`src/chatterbox/text_ru.py` — нормализация русского текста** (вызывается автоматически при `language_id="ru"`):
- Числа словами (через num2words).
- Порядковые: `5-й`, `5-я`, `5-го`, `на 5-м` → «на пятом».
- **Годы согласуются с предлогом:** `в 2026 г.` → «в две тысячи двадцать шестом году», `с 1999 года` → «с … девяносто девятого года», `к 2030 году` → «к … тридцатому году».
- **Единицы согласуются с числом:** `3 км` → «три километра», `21 мин` → «двадцать одна минута», `за 21 мин` → «за двадцать одну минуту», `%`, `руб.`, `₽`, `$`, `кг`, `сек`, `коп.`.
- Сокращения: т.е., т.к., и т.д., и т.п., в т.ч., ул., д., кв., гг.
- **Латиница:** модель её не читает. Известные названия переводятся в русское написание (ChatGPT → «чат джи пи ти», Claude, YouTube, Telegram…), а сокращения капсом читаются по буквам.
- **Разметка листов для записи:** убираются заголовки `[Куплет]`, ремарки `(тише)` и метки вдоха `|`. Номера строк `01 …` убираются, только если 3+ строки подряд пронумерованы — так «15 минут» в начале строки не теряет число.

**`src/chatterbox/postfx.py` — чистка звука:**
- **Проблема:** после последнего слова модель иногда ещё 1–2 секунды «дышит» или бормочет на 12–25 дБ тише речи, а перед фразой бывает вдох.
- Фраза делится на звуковые сегменты по паузам. Тихие крайние сегменты (вдох, бормотание) отрезаются.
- Паузы глушатся, а паузы длиннее 0,6 с укорачиваются до 0,45 с.
- Громкость выравнивается одним линейным усилением. Динамический `loudnorm` специально убран: он поднимал шипение в паузах обратно, это проверено замером.

**`src/chatterbox/asr_qa.py` — проверка на слух локальным Whisper** (необязательно, нужен `faster-whisper`):
- Каждую фразу распознаёт `faster-whisper small` (int8, CPU).
- Хвост отрезается сразу после последнего распознанного слова.
- Если услышано меньше 90% слов текста, фраза перегенерируется, до 2 повторов, и берётся лучший дубль.

**`say.py` — CLI:**
- Режет текст на фразы до ~100 символов: на коротких фразах модель заметно стабильнее.
- Ограничивает длину генерации по числу слогов, чтобы модель не «досочиняла» речь после текста.
- Добавляет мягкий заход «… » перед фразой: без него модель часто съедала первую согласную («Пятый» → «Татый»).
- Склеивает фразы с паузами и пишет MP3 или WAV.

## Установка

Проверено на Linux, Python 3.11, torch 2.6.0 (CPU).

```bash
uv venv -p 3.11 .venv
uv pip install -p .venv/bin/python chatterbox-tts==0.1.7    # зависимости оригинала (torch, transformers, ...)
uv pip uninstall -p .venv/bin/python chatterbox-tts         # сам оригинал не нужен
uv pip install -p .venv/bin/python -e . --no-deps           # этот форк
uv pip install -p .venv/bin/python -r requirements-pdzd.txt # setuptools<81, ruaccent, num2words, faster-whisper
```

Для MP3 нужен `ffmpeg`.

`setuptools<81` обязателен: водяной знак Perth импортирует `pkg_resources`, без него генерация падает с `'NoneType' object is not callable`.

## Использование

```bash
# один раз: профиль голоса из своего образца (10–30 с чистой речи без музыки)
.venv/bin/python say.py --voice my_voice.wav --save-voice voices/me.pt

# озвучка
.venv/bin/python say.py --voice voices/me.pt --text-file text.txt --out out.mp3
```

| Параметр | Что делает |
|---|---|
| `--steps 10` | Шаги декодера звука. 10 — как в оригинале, 6 — примерно на 30% быстрее на CPU. |
| `--emotion 0.5` | 0.25 — ровно, по-дикторски; 0.8 — живее. |
| `--pace 0.5` | cfg_weight: меньше — свободнее, больше — размереннее. |
| `--retakes 2`, `--no-qa` | Повторы при проглоченных словах; `--no-qa` отключает проверку Whisper (быстрее, но без обрезки хвостов и повторов). |
| `--pause 0.35` | Пауза между фразами, в секундах. |
| `--dump-phrases DIR` | Сохранить сырые фразы, чтобы настроить чистку через `tests/retune.py`. |

## Замеры

Всё на одном ноутбуке: Intel i5-10210U (4 ядра / 8 потоков), только CPU.

- **Скорость.** Обычный текст, `--steps 6`, с проверкой Whisper: 12,7 с речи за ~4 минуты, считая загрузку модели. Тест-скороговорка `tests/twister.txt`, `--steps 10`: 71 с речи за 25 минут, потому что сложные фразы перегенерировались по 3 раза. Это **медленно**: озвучка на CPU — для коротких текстов, а не для книг.
- **Обрыв фраз и «досочинение».** До исправлений длинная фраза длилась 20,4 с вместо ~9 с. После разбиения на фразы и ограничения длины длительность стабильна от прогона к прогону.
- **Паузы.** До чистки между фразами было 0,5–1,4 с шипения на уровне −57…−65 дБ. После — тишина, паузы ровные, ~0,4 с.
- **Тест `tests/twister.txt` клоном голоса, 20 фраз.** По Whisper 15 фраз распознаны на 100%, остальные — на 73–93%. Омографы, годы, проценты, сокращения и вопросы прочитаны правильно.

## Ограничения (что не работает или не проверено)

- **Скороговорки с плотными согласными.** «Карл у Клары украл кораллы», «сыворотка из-под простокваши» звучат смазанно даже после трёх дублей. Это предел самой модели.
- **Падеж числа без предлога не угадывается.** «Шли 21 мин» → «двадцать одна минута», а не «минуту». Где падеж важен, пишите число словами.
- **Десятичные дроби** читаются упрощённо («два и пять»), время вида `7:45` не обрабатывается.
- **Латиница:** только слова из словаря и сокращения капсом. Остальное модель прочитает как сможет.
- **Whisper — приблизительная метрика.** Он сам ошибается («Тятый» вместо «Пятый») и не оценивает тембр и интонацию. Похожесть голоса никак не измерялась, её оценивал на слух один человек.
- **Не проверено:** GPU, macOS и Windows, языки кроме русского (исправления 1, 3, 4 касаются всех языков, но тестировался только русский), рэп и пение. Автоматических юнит-тестов нет, только ручные прогоны из `tests/`.
- Форк не синхронизирован с апстримом и не собирается на PyPI.

## Этика и водяной знак

- **Клонируйте только свой голос или голос человека, который явно согласился.** Не используйте форк для выдачи себя за другого человека.
- Водяной знак **Perth** от Resemble AI **оставлен включённым**: сгенерированное аудио помечено как синтетическое. Форк его не отключает и не собирается.
